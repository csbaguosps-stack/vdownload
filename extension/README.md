# VDownload Pro - Browser Extension (Standalone & Web Helper)

Ekstensi resmi browser (Google Chrome, Microsoft Edge, Brave, Opera) untuk **VDownload Pro**.
Dapat berjalan **100% Berdiri Sendiri (Standalone)** langsung di browser tanpa memerlukan server lokal / XAMPP menyala, atau terhubung sebagai pendamping website VDownload Pro.

## 🌟 Fitur Utama Ekstensi

1. **⚡ Standalone Direct Downloader (100% Berdiri Sendiri)**:
   - Mengekstrak dan mengunduh video & musik YouTube, YouTube Music, TikTok, Shopee Video, dan Instagram langsung di browser.
   - Pilihan resolusi lengkap: Video 1080p Full HD, HD 720p, SD 360p (Hemat Kuota), Audio MP3 320k Studio Quality, musik M4A, serta cover album artwork resolusi penuh.
   - File langsung diunduh ke folder Downloads komputer via API Chrome Downloads!

2. **🎯 Deteksi Tab Aktif Otomatis**:
   - Mendeteksi secara instan jika tab aktif adalah video YouTube (Video & Shorts), YouTube Music (`music.youtube.com`), TikTok, Instagram Reels, atau Shopee Video.
   - Cukup klik ikon ekstensi &rarr; klik **Unduh Media di Tab Ini**.

3. **🔘 Tombol Unduh Mengambang Standalone (Floating Button)**:
   - Muncul di pojok kanan bawah saat membuka video/lagu di YouTube, YouTube Music, TikTok, Instagram, atau Shopee.
   - Klik tombol &rarr; panel instan muncul langsung di halaman &rarr; pilih resolusi Video HD atau Musik MP3 &rarr; file langsung terunduh ke komputer Anda!

4. **🔄 Tombol Reload Ekstensi Cepat**:
   - Tersedia tombol reload instan di header popup dan tab alat untuk memuat ulang ekstensi tanpa membuka menu browser.

## 🚀 Cara Pemasangan (Instalasi) di Browser

Ekstensi ini siap digunakan langsung menggunakan fitur **Developer Mode** bawaan Chrome/Edge tanpa perlu akun developer:

### 1. Untuk Google Chrome & Brave:
1. Buka browser Chrome, lalu buka:
   ```
   chrome://extensions
   ```
2. Di pojok kanan atas, aktifkan tombol **Mode pengembang** (*Developer mode*).
3. Klik tombol **Muat yang belum dibongkar** (*Load unpacked*) di pojok kiri atas.
4. Pilih folder ekstensi ini:
   ```
   C:\xampp\htdocs\vdownload\extension
   ```
5. Selesai! Ekstensi **VDownload Pro** akan muncul di toolbar browser dan siap digunakan 100% mandiri.

### 2. Untuk Microsoft Edge:
1. Buka Microsoft Edge, lalu buka:
   ```
   edge://extensions
   ```
2. Di menu samping kiri, aktifkan toggle **Mode Pengembang** (*Developer mode*).
3. Klik tombol **Muat yang belum dibongkar** (*Load unpacked*).
4. Pilih folder: `C:\xampp\htdocs\vdownload\extension`.
5. Selesai!
